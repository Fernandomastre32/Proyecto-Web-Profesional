Bienvenido

Esta aplicación tiene como objetivo explicar los principales conceptos relacionados con la estructura, navegación y búsqueda en sitios web, utilizando Angular como framework de desarrollo.

Breadcrumbs

Los breadcrumbs o migas de pan permiten al usuario conocer su ubicación dentro del sitio web. En Angular, se suelen implementar utilizando el sistema de rutas (Router) para mostrar el camino de navegación de forma clara y dinámica.

Tipos de búsqueda

Un sitio web puede incluir distintos tipos de búsqueda, como la búsqueda simple por texto, búsqueda filtrada o búsqueda avanzada. En Angular, estas funciones se integran fácilmente mediante formularios reactivos y componentes reutilizables.

Estructura del sitio web

La estructura define cómo se organizan las páginas y componentes. Angular permite una arquitectura modular, donde cada sección del sitio se divide en componentes, módulos y rutas, facilitando el mantenimiento y la escalabilidad.

Navegación

La navegación es la forma en que el usuario se mueve entre las distintas secciones del sitio. En Angular, se gestiona principalmente mediante routerLink, menús y breadcrumbs, asegurando una experiencia fluida sin recargar la página.
